# Shubhanu Chatterjee — Portfolio

A React + Vite portfolio site for Shubhanu Chatterjee, DSAI student at IIIT Dharwad.

## Run locally

```bash
npm install
npm run dev
```

## Publish free with GitHub Pages

1. Create a public GitHub repository named `portfolio` under `shubhanu-code`.
2. Push this project to its `main` branch.
3. In the repository: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Add a standard Vite GitHub Pages workflow, then publish. The eventual URL will be `https://shubhanu-code.github.io/Portfolio/`.

This URL is a planned convention—not a claim that the site is deployed.
